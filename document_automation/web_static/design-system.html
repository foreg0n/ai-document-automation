01 / Foundations

Type scale

Inter 400 / 500 / 600. JetBrains Mono for identifiers, dates, amounts, and code. Body text is 16px / 1.5; supporting labels use 12px or 14px.

02 / Component states

Default, hover, focus-visible, pressed, disabled, loading, error, and success. Semantic states apply to the action or surrounding region. Keyboard focus uses a 2px indigo outline.

Button variants

One primary action per product screen. Destructive actions use a concrete confirmation. Disabled actions explain what is needed to continue.
